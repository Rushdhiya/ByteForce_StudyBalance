# ByteForce_StudyBalance
StudyBalance is a student-focused web application designed to help university students manage their study activities and maintain a healthy balance between academic responsibilities and daily life. Built with Java Spring Boot, Spring Security, MySQL, and HTML, CSS, and JavaScript.

# StudyBalance – Backend

## Overview
The backend of StudyBalance handles the application's server-side operations, business logic, data processing, and database communication.

## Technologies Used
- Java
- Spring Boot
- Spring Security
- MySQL
- Maven
- REST API

## Main Responsibilities
- Handle client requests and responses.
- Manage application business logic.
- Perform database operations.
- Provide RESTful API endpoints.
- Handle authentication and authorization.
- Validate and process user data.

## Project Structure
```text
backend/
├── src/
│   └── main/
│       ├── java/
│       └── resources/
├── pom.xml
├── mvnw
└── mvnw.cmd
```

## Running the Backend
1. Navigate to the backend directory.
2. Configure the database connection.
3. Make sure MySQL is running.
4. Run the following command:

```bash
./mvnw spring-boot:run
```

On Windows PowerShell:

```powershell
.\mvnw.cmd spring-boot:run
```

# StudyBalance – Frontend

## Overview
The frontend of StudyBalance provides the user interface through which students interact with the application. It focuses on usability, responsiveness, and a user-friendly experience.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Main Responsibilities
- Display application pages and interfaces.
- Provide user-friendly navigation.
- Collect and display user information.
- Communicate with the backend REST APIs.
- Display application data dynamically.
- Provide responsive layouts for different screen sizes.

## Project Structure
```text
frontend/
├── css/
├── js/
├── images/
└── index.html
```

## Running the Frontend
1. Navigate to the frontend directory.
2. Open `index.html` in a web browser.
3. Ensure the backend server is running for API-based features.
